# CrossTwins v1.6.5-ct.1 — 최초 시험판

CrossTwins의 첫 공개 시험판입니다. CrossPoint 1.6.5를 기반으로 한국어 사용자 경험과 XTeink X3/X4 동작을 검증합니다. CrossTwins는 CrossPoint-KO를 그대로 이식한 버전이 아니라 독립적인 커뮤니티 포크입니다.

## 다운로드

- XTeink X3 / X4: `crosspoint-1.6.5-ct.1-x3-x4.bin`
- X4 Classic: `crosspoint-1.6.5-ct.1-x4c.bin`
- X4 Pro: `crosspoint-1.6.5-ct.1-x4pro.bin`
- Seeed reTerminal Sticky: `crosspoint-1.6.5-ct.1-sticky.bin`
- M5Stack Paper Mono: `crosspoint-1.6.5-ct.1-papermono.bin`

X3와 X4는 동일한 ESP32-C3 firmware image를 사용합니다. X4 Classic, X4 Pro, Sticky, Paper Mono는 CI 빌드 대상이지만 실기기 검증을 완료하지 않았습니다. 해당 기기에서는 시험판으로만 사용해 주세요.

## 설치 전 확인

- 설치 전에 현재 firmware와 SD 카드 데이터를 백업하세요.
- 기기 모델에 해당하는 `.bin`만 사용하세요.
- 이 버전은 시험판이며 예상하지 못한 문제가 있을 수 있습니다.
- CrossTwins 전용 OTA 배포는 지원하지 않습니다. 기기의 OTA 확인 기능은 공식 CrossPoint Release를 조회하므로, OTA 화면에 업데이트가 표시되면 CrossTwins 업데이트로 간주하지 말고 취소하세요.
- 문제 보고에는 기기 모델, Settings에 표시된 firmware version, 사용한 asset 이름과 재현 방법을 포함해 주세요.

## 빌드 정보

- Base: CrossPoint `1.6.5`
- Tag: `v1.6.5-ct.1`
- 내부 firmware version: `1.6.5-ct.1+<7자리 commit SHA>`
- SDK: `539da34db67a546cad961525d7e9b6364dfa2fe4`

이번 시험판은 별도의 CrossTwins OTA endpoint를 추가하지 않습니다. OTA 및 Firmware Switcher는 후속 설계·구현 범위입니다.
